# Cómo descargar el Manual del Administrador en PDF

## Archivo principal

Abra en su navegador (Chrome o Edge recomendado):

**`MANUAL_ADMINISTRADOR_PDF.html`**

Ruta completa en este proyecto:

`docs/administrador/MANUAL_ADMINISTRADOR_PDF.html`

## Pasos para generar el PDF

1. Abra el archivo `.html` con **doble clic** o arrástrelo al navegador.
2. Espere **10–20 segundos** para que los diagramas Mermaid terminen de dibujarse.
3. Pulse **Ctrl + P** (Imprimir).
4. Destino: **Guardar como PDF** / **Microsoft Print to PDF**.
5. Opciones recomendadas:
   - **Márgenes:** Predeterminado o Estrecho
   - **Escala:** 100 %
   - **Gráficos de fondo:** Activado (para conservar colores de portada y tablas)
6. Guarde como: `Manual_Administrador_SOLAINO.pdf`

## Imágenes incluidas

Las capturas de pantalla están en la carpeta **`imagenes/`** (copia de `IMG-SOLAINO/manual_admin`). Si mueve el HTML, lleve la carpeta `imagenes` junto con él.

## Actualizar capturas

Si cambia pantallas del sistema, reemplace los PNG en `imagenes/` manteniendo el mismo nombre de archivo, o edite las rutas en el HTML.
